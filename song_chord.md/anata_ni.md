# Anata ni: Gesture Synth

**Key:** A

## Left hand: chord

| Chord | Gesture | Fingers up | Tilt |
|---|---|---|---|
| F#m | 🤘↖ | Index + pinky | Left (outward, minor) |
| A | 1↗ | Index | Right (inward, major) |
| Bm | 2↖ | Index + middle | Left (outward, minor) |
| C#m | 3↖ | Index + middle + ring | Left (outward, minor) |
| Db (displays as C#) | 3↗ | Index + middle + ring | Right (inward, major) |
| D | 4↗ | All four fingers, thumb tucked | Right (inward, major) |
| Dm | 4↖ | All four fingers, thumb tucked | Left (outward, minor) |
| E | 5↗ | Open hand, including thumb | Right (inward, major) |

## Right hand: voicing and volume

- **Fingers:** Index up, thumb tucked, for every chord. A closed fist is silent.
- **Volume:** Raise your hand to play louder, lower it to play softer.
- **Filter:** Keep your hand upright for a neutral sound.

## Chorus

`•` marks the syllable before each chord: start the gesture there so the sound lands on time. The first chord has no syllable before it, so form that gesture before you start singing.
